One roast line for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty: a single sentence under 200 characters roasting a smart fridge. The program writes the line to `/output/entry.txt` — the fridge lectures its owner about milk expiring in two days while running firmware from 2019 that expired in 2021. The fridge judges the human and is itself guilty, and the last words carry the laugh.

## Run it

```sh
python3 main.py
```
